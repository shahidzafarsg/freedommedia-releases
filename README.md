# FreedomMedia downloads

A private, encrypted vault for your photos and videos, by [freedomsoft.uk](https://freedomsoft.uk).

This repository holds the official FreedomMedia installers only. Download the latest version from
the [Releases page](https://github.com/shahidzafarsg/freedommedia-releases/releases/latest).

To report a problem or ask a question, open an [issue](https://github.com/shahidzafarsg/freedommedia-releases/issues).
